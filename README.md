# 감사 열매 농장

소년부 12개 반(믿음·소망·사랑 × 4반)이 함께하는 30분짜리 반 대항 레크 웹앱이에요.
반마다 열매 10개로 시작해 8라운드 동안 정의 창고로 이웃 마을을 세우고, 감사 농사 문제를 풀고, 12개 반 공동 '감사 창고'에 열매를 얼마나 나눌지 정해요.

## 화면

| 주소 | 누가 | 하는 일 |
| --- | --- | --- |
| `/` | 진행자 | 새 세션 열기 / 이어서 진행하기 (세션을 연 기기가 진행자) |
| `/control?s=세션` | 진행자 노트북 | 단계 진행, 정답·인카운터 공개, 되돌리기, 열매 조정, 반 선택 해제, 출력 화면 QR 띄우기 |
| `/display?s=세션` | 프로젝터 | 시작 전에는 참여 QR, 이후 문제·타이머·12개 반 열매판·결과 (컨트롤의 "출력 창 열기"로 연다) |
| `/t?s=세션&k=참여키` | 반 선생님 휴대폰 | 참여 QR로 접속 → 드롭다운에서 반 선택 → 감사 농사 답, 정의·감사 창고 숫자 제출 (로그인 없음) |

## 규칙 요약

- 라운드: 정의 창고 → 감사 농사 1문제 → 감사 창고 → 랜덤 인카운터 → 분배
- 정의 창고와 감사 창고 숫자는 반 친구들이 선생님 휴대폰으로 한 명씩 입력하고, 그 평균(소수점 버림)이 제출돼요.
- 정의 창고: 낸 열매는 사라지고, 모든 반이 낸 열매가 누적 24개 모일 때마다 이웃 마을 1개가 생겨요. 새 마을은 그 라운드에 1개 이상 낸 반의 '우리 반 마을'이 돼요(얼마를 냈든 같음). 늦게 내기 시작한 반은 그 전에 생긴 마을을 얻지 못해요.
- 감사 농사: 맞힌 반은 이번 추수에 창고에 넣지 않고 남긴 열매가 ×2.0으로 불어나요. 그 라운드 정의 창고에 1개 이상 낸 반은 우리 반 마을 1개당 +0.3. 틀리면 그대로예요.
- 반마다 받는 열매 = 감사 창고 합계 × 인카운터 배수 ÷ 참여 반 수 (버림)
- 인카운터: 좋음(창고 ×2) · 보통(×1.5) · 나쁨(×1.5, 남긴 열매 절반) 중 하나를 같은 확률로 뽑아요. 계절과 상관없고 같은 날씨가 반복될 수 있어요.
- 남긴 열매 계산 순서: 감사 농사 배율 → 날씨(나쁨이면 절반), 각 단계 버림
- 공동우승: 모든 반이 150개 이상
- 문제는 세트로 나뉘어 있어요 (`QUESTION_SETS`). 기본은 2회차 문제이고, 진행자 화면 시작 전에 1회차 문제로 바꿀 수 있어요. 세트를 하나 더 추가하면 선택 목록에 바로 나타나요.
- 숫자(배율·마을 기준·공동우승 기준)와 문제·인카운터는 `public/js/data.js` 에서 고쳐요.

## 개발

```bash
npm test                     # 게임 로직 테스트
npm run emulators            # Firestore·Auth·Hosting 에뮬레이터 (http://127.0.0.1:5000)
npm run deploy               # 보안 규칙 + 호스팅 배포 (firebase login 필요)
```

Firebase 콘솔에서 미리 할 일: Firestore 데이터베이스 만들기(asia-northeast3), Authentication → 익명 로그인 사용.

`public/js/fb.js` 의 웹앱 설정값은 원래 공개되는 값이에요. 데이터 접근은 `firestore.rules` 가 막아요.

- 진행자: 세션을 처음 연 기기만 `games/{세션}/admins/{uid}` 로 등록돼요.
- 반 선생님: 참여 키(QR)를 알아야 반을 고를 수 있고, 한 반은 한 기기만 고를 수 있어요.
- 제출: 그 반을 고른 기기만, 열려 있는 단계에서만 낼 수 있어요.
