# 감사 열매 농장

소년부 12개 반(믿음·소망·사랑 × 4반)이 함께하는 30분짜리 반 대항 레크 웹앱이에요.
반마다 열매 10개로 시작해 4계절 × 2라운드 = 8라운드 동안 감사 농사 문제를 풀고, 12개 반 공동 '감사 창고'에 열매를 얼마나 나눌지 정해요.

## 화면

| 주소 | 누가 | 하는 일 |
| --- | --- | --- |
| `/` | 진행자 | 새 세션 열기 / 이어서 진행하기 (세션을 연 기기가 진행자) |
| `/control?s=세션` | 진행자 노트북 | 단계 진행, 정답·인카운터 공개, 되돌리기, 열매 조정, 반 선택 해제, 출력 화면 QR 띄우기 |
| `/display?s=세션` | 프로젝터 | 시작 전에는 참여 QR, 이후 문제·타이머·12개 반 열매판·결과 (컨트롤의 "출력 창 열기"로 연다) |
| `/t?s=세션&k=참여키` | 반 선생님 휴대폰 | 참여 QR로 접속 → 드롭다운에서 반 선택 → 감사 농사 답, 창고 숫자 제출 (로그인 없음) |

## 규칙 요약

- 라운드: 감사 농사 1문제(맞히면 +2) → 창고 회의·제출 → 랜덤 인카운터 → 분배
- 반마다 받는 열매 = 창고 합계 × 인카운터 배수 ÷ 12 (버림)
- 일부 인카운터는 창고에 넣지 않고 남긴 열매를 절반(꽃샘추위·태풍·메뚜기 떼·까마귀 떼) 또는 1/4(폭염)로 줄여요.
- 같은 계절의 두 라운드에는 같은 인카운터가 나오지 않아요.
- 문제는 세트로 나뉘어 있어요 (`QUESTION_SETS`). 기본은 2회차 문제이고, 진행자 화면 시작 전에 1회차 문제로 바꿀 수 있어요. 세트를 하나 더 추가하면 선택 목록에 바로 나타나요.
- 문제·인카운터는 `public/js/data.js` 에서 고쳐요.

## 개발

```bash
npm test                     # 게임 로직 테스트
npm run emulators            # Firestore·Auth·Hosting 에뮬레이터 (http://127.0.0.1:5000)
npm run deploy               # 보안 규칙 + 호스팅 배포 (firebase login 필요)
```

Firebase 콘솔에서 미리 할 일: Firestore 데이터베이스 만들기(asia-northeast3), Authentication → 익명 로그인 사용.

`public/js/fb.js` 의 웹앱 설정값은 원래 공개되는 값이에요. 데이터 접근은 `firestore.rules` 가 막아요.

- 진행자: 세션을 처음 연 기기만 `games/{세션}/admins/{uid}` 로 등록돼요.
- 반 선생님: 참여 키(QR)를 알아야 반을 고를 수 있고, 한 반은 한 기기만 고를 수 있어요.
- 제출: 그 반을 고른 기기만, 열려 있는 단계에서만 낼 수 있어요.
